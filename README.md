**Sales Performance & Revenue Analytics Dashboard | Microsoft Excel**

* Developed an interactive sales performance dashboard using Excel to analyze revenue, profitability, order volume, regional performance and salesperson productivity.
* Cleaned and transformed 5,000+ sales transaction records using Excel data-cleaning techniques and structured analytical tables.
* Built PivotTables, PivotCharts, KPI calculations and interactive slicers to provide dynamic analysis across regions, categories, products and salespersons.
* Created KPIs including Total Sales, Profit, Profit Margin, Average Order Value, Units Sold and Target Achievement.
* Conducted monthly, regional and product-level sales analysis to identify revenue trends, target gaps and high-performing product categories.
* Performed Top/Bottom product and salesperson analysis to identify business performance drivers and improvement opportunities.
* Presented actionable business insights through an interactive management dashboard designed to support sales planning and decision-making.
